PROJEKT 3: Szerokopasmowy Odbiornik Remote ID z Dedykowaną Aplikacją Python

Zintegrowany system nasłuchowy przeznaczony do detekcji, przechwytywania oraz dekodowania transmisji Remote ID nadawanych na pasmach **2.4 GHz** oraz **5.8 GHz**.

2.4 GHz & 5.8 GHz Band Python Engine Real-time Parsing Packet Inspection

1. Architektura Radiowa i Odbiór Sygnału

  • Szerokopasmowy skaner RF: Symultaniczna praca w paśmie ISM 2.4 GHz (Bluetooth LE, Wi-Fi Beacon) oraz 5.8 GHz (transmisje analogowe/cyfrowe o wysokiej przepustowości).
  • Korekcja błędów i detekcja słabych sygnałów: Zastosowanie filtrów cyfrowych pozwalających wyłowić ramki Remote ID z tła szumów elektromagnetycznych.

2. Silnik Analityczny w Języku Python

Oprogramowanie napisane w środowisku Python analizuje odebrane pakiety binarne w czasie rzeczywistym i wyciąga kluczowe dane telemetryczne:

  • Dekodowanie telemetrii: Pozycja GPS drona, wysokość barometryczna/nad poziomem morza, wektor prędkości i kierunek lotu.
  • Lokalizacja pilota: Wyodrębnienie współrzędnych geograficznych punktu startu (Home Location) oraz pozycji aparatu sterującego (Operator Position).
  • Eksport danych: Możliwość przekazywania danych do formatów JSON, KML (dla Google Earth) oraz wypychanie strumienia na serwery telemetryczne.

3. Analiza Zgodności ze Standardami

Aplikacja weryfikuje spójność i poprawność struktury odebranych ramek z międzynarodowymi normami:

  • Sprawdzanie sum kontrolnych i ciągłości pakietów wg **ANSI/CTA-2063-A** (struktura numeru seryjnego).
  • Weryfikacja stempli czasowych zgodnie z dyrektywami **EASA** oraz **FAA**.
