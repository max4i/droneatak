Szerokopasmowy Odbiornik Remote ID

DRONE ATAK MX • odbiornik 2,4 GHz + 5,8 GHz + BLE 4.2/5.0 • wyjście COM oraz CoT do TAK.

O odbiorniku — ogólne informacje

Odbiornik szerokopasmowy DroneAtak to urządzenie nasłuchujące pracujące na platformie ESP32-C5, które jednocześnie odbiera i dekoduje pakiety Remote ID w trzech pasmach radiowych: Wi-Fi 2,4 GHz, Wi-Fi 5,8 GHz oraz Bluetooth 4.2 i 5.0. Urządzenie jest przeznaczone do szkolenia, testów zgodności Remote ID oraz integracji z systemami świadomości sytuacyjnej TAK/ATAK.

Odbiornik jest kompatybilny z dowolnym nadajnikiem Remote ID zgodnym z normami ASTM F3411 i ASD-STAN — zarówno komercyjnym, jak i wojskowym. Dane są przekazywane na bieżąco do komputera PC przez port COM (USB-Serial) oraz — opcjonalnie — do oprogramowania TAK przez protokół CoT.

ESP32-C5 Wi-Fi 2,4 GHz Wi-Fi 5,8 GHz BLE 4.2 / 5.0 ASTM F3411 ASD-STAN COM / USB-Serial CoT / TAK

Pasma odbiorcze

Odbiornik obsługuje jednocześnie wszystkie pasma wykorzystywane przez systemy Remote ID:

  • Wi-Fi 2,4 GHz (802.11 b/g/n): odbiór ramek Beacon z Vendor Specific IE — podstawowy kanał transmisji Remote ID w standardzie Wi-Fi.
  • Wi-Fi 5,8 GHz (802.11 a/n/ac): odbiór ramek w wyższym paśmie — dla nowoczesnych systemów Remote ID pracujących w 5 GHz.
  • Bluetooth 4.2 (BLE Legacy): odbiór klasycznych reklam BLE z Service Data 0xFFFA.
  • Bluetooth 5.0 (BLE Extended): odbiór nowszych reklam BLE z rozszerzonym zasięgiem i większą przepustowością.

Wszystkie pasma są nasłuchiwane równolegle — odbiornik nie wymaga przełączania trybów. Dzięki temu jedno urządzenie pokrywa całe spektrum komunikacji Remote ID stosowane zarówno w Europie, jak i w USA.

Dekodowanie Remote ID

Odbiornik dekoduje pełny zestaw komunikatów Remote ID zgodnych z ASTM F3411 / ASD-STAN:

  • Basic ID — tożsamość drona (typ, numer seryjny / nazwa BLE).
  • Location — pozycja, wysokość, kurs, prędkość, dokładność.
  • System — pozycja operatora, obszar operacyjny, pułap.
  • Operator ID — identyfikator operatora (np. POL-OP-SWARM-01).
  • Self ID — dodatkowy opis (np. grupa taktyczna, model).

Dane są wyświetlane w dedykowanej aplikacji w czasie rzeczywistym oraz zapisywane w formacie JSON / CSV do dalszej analizy. Odbiornik obsługuje również filtrowanie po numerze seryjnym, modelu lub ID operatora.

Współpraca z Windows przez port COM

Odbiornik komunikuje się z komputerem PC przez port COM (USB-Serial). Po podłączeniu do Windows urządzenie pojawia się jako wirtualny port szeregowy i wysyła dane w formacie JSON — jedna linia na każdy odebrany pakiet Remote ID.

  • Prędkość: 115200 bps (lub 921600 bps w trybie szybkim).
  • Format: JSON — każda linia to jeden obiekt Remote ID.
  • Dedykowane oprogramowanie: aplikacja Windows do wizualizacji, rejestracji i analizy danych.
  • Kompatybilność: dowolny terminal szeregowy (PuTTY, Termite, RealTerm) oraz własne skrypty w Pythonie.

Dzięki temu odbiornik można łatwo zintegrować z istniejącymi systemami szkoleniowymi lub własnymi narzędziami analitycznymi.

Współpraca z oprogramowaniem TAK przez protokół CoT

Odbiornik może jednocześnie wysyłać odebrane dane do oprogramowania TAK / ATAK / WinTAK przez protokół CoT (Cursor on Target). Dzięki temu wszystkie wykryte drony pojawiają się na mapie taktycznej w czasie rzeczywistym.

  • Transport: UDP broadcast / multicast / TCP / TLS.
  • Częstotliwość: 0,2 – 5 Hz (konfigurowalna).
  • Pola CoT: spójne z tożsamością Remote ID (uid = serial, callsign = bleName, operator = operatorId, grupa = groupName, model = modelName).
  • Typ CoT: a-f-A-M-Q (standardowy dla drona).
  • Ikonka ATAK: konfigurowalna (np. UAV_FixedWing.png).

Odbiornik może pracować równocześnie w trybie COM (dla Windows) i CoT (dla TAK) — dane są wysyłane do obu odbiorców jednocześnie.

Zastosowanie

Odbiornik wspiera trzy główne obszary szkoleniowe:

  • Ośrodki szkoleniowe: weryfikacja zgodności nadajników Remote ID, testy zasięgu i skuteczności, szkolenie operatorów systemów wykrywania.
  • Jednostki MON i WOT: szkolenie personelu C-UAS, testy integracji z TAK/ATAK, ćwiczenia z zakresu świadomości sytuacyjnej.
  • Pasjonaci nowej technologii militarnej: samodzielne testy własnych nadajników Remote ID, analiza sygnałów w pasmach 2,4 / 5,8 GHz, nauka dekodowania ASTM F3411.

Odbiornik jest szczególnie przydatny w połączeniu z symulatorem DroneAtak i nadajnikiem Remote ID — tworzy wtedy kompletny łańcuch szkoleniowy: emisja (symulator + nadajnik) → odbiór (odbiornik) → analiza (Windows + TAK).

Dane techniczne

Platforma: Espressif ESP32-C5 — jednordzeniowy procesor RISC-V, 240 MHz, obsługa Wi-Fi 2,4 GHz i 5 GHz (dual-band) oraz Bluetooth 5 LE. Interfejs USB-Serial/JTAG. Zasilanie 5 V przez USB-C — pobór prądu 0,25 A (1,25 W).

Zasięgi i anteny:

  • Antena GP 5/8 (2,4 GHz): zasięg do ~300 m.
  • Antena 5,8 GHz (w zestawie): zasięg do ~200 m.
  • Antena kierunkowa 8–12 dBi (opcja): zasięg do ~800 m.
  • Czułość odbioru: do −98 dBm (BLE), do −95 dBm (Wi-Fi).

Zasilanie: 5 V przez USB-C (0,25 A), możliwość zasilania z powerbanku, ładowarki sieciowej lub portu USB komputera.

Współpraca z symulatorem i nadajnikiem

Odbiornik jest trzecim elementem kompletnego łańcucha szkoleniowego DroneAtak:

  • Symulator DroneAtak — generuje rój do 200 wirtualnych dronów i wysyła ich dane Remote ID.
  • Nadajnik Remote ID — emituje rzeczywisty sygnał Remote ID z możliwością ustawienia dowolnych danych i trybu echa.
  • Odbiornik szerokopasmowy — odbiera wszystkie sygnały, dekoduje je i przekazuje do Windows (COM) oraz TAK (CoT).

Dzięki temu można prowadzić pełne ćwiczenia: symulacja ataku rojowego + rzeczywisty dron pilota + fałszywe echa + odbiór i analiza w TAK. Wszystko bez konieczności użycia realnych platform bojowych.

Podsumowanie

Odbiornik szerokopasmowy DroneAtak to kompletne narzędzie do odbioru i analizy sygnałów Remote ID w pasmach 2,4 GHz, 5,8 GHz oraz BLE 4.2 i 5.0. Dzięki równoległemu nasłuchowi wszystkich pasm, dekodowaniu pełnego zestawu komunikatów ASTM F3411 / ASD-STAN oraz jednoczesnej współpracy z Windows (COM) i TAK (CoT), urządzenie sprawdzi się w każdym ośrodku szkoleniowym — cywilnym, wojskowym i pasjonackim.

Odbiornik jest zasilany z 5 V / 0,25 A, zamknięty w obudowie drukowanej w 3D z PETG i wyposażony w anteny GP 5/8 (2,4 GHz) oraz 5,8 GHz, co zapewnia zasięg do ~300 m w otwartej przestrzeni.
